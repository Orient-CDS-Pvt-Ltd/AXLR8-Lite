AXLR8 Lite

Free, open-source AI chat for SAP ABAP development in Eclipse — reads your active editor, knows your SAP release, works with Claude Code or GitHub Models.

This page is an Eclipse p2 update site — it is meant to be used from inside Eclipse, not a browser. The plugin files (content.jar, artifacts.jar) are served from this address.

Install in Eclipse

  1. In Eclipse: Help → Install New Software… → Add…
  2. Paste this location:
https://orient-cds-pvt-ltd.github.io/AXLR8-Lite/
  1. Select AXLR8 Lite → Next → Finish → restart Eclipse.
  2. Open the view: Window → Show View → Other → Orient AXLR8 Lite → AXLR8 Lite Chat (or Ctrl+Shift+A).

Or install from the Eclipse Marketplace — search for “AXLR8 Lite”. Requires Eclipse 2024-09+ and Java 17+.
